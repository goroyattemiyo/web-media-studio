## Current product state

WMS is a mobile-first PWA containing these UI v2 tool cards:

1. Player
2. Library
3. YouTube
4. Localize
5. Recorder
6. Audio tools
7. Device check

UI v2 uses a horizontal swipe / scroll-snap tool deck with a compact navigation bar and previous/next pager. A custom background image can be stored locally in IndexedDB with dim/blur controls. Existing panels remain mounted while moving between cards so media state is preserved.

## YouTube official player

The official YouTube IFrame provider is implemented and working for normal foreground playback.

Known, validated limitation:

- Android screen-off/background playback of the embedded YouTube player stops.
- `Keep screen on` uses Screen Wake Lock only to prevent automatic screen-off while visible; it does not make screen-off YouTube playback work.
- Do not claim embedded YouTube background/screen-off playback is supported.

The local Player and YouTube player currently have independent playback state, so simultaneous playback is still possible.

## Recorder

### Existing mic recording

Recorder originally supported microphone-only practice recording and `Play & Record` with a local WMS source. Takes are stored in IndexedDB and can be saved to device.

### PR #30 — current-tab audio capture

PR #30 merged and GitHub Pages build/deploy passed.

Implemented recorder capture modes:

- `Mic`
- `Tab audio`
- `Tab + Mic`

Implementation details:

- Uses `navigator.mediaDevices.getDisplayMedia({ video: true, audio: true })` for tab/display capture.
- Records only the resulting audio stream with `MediaRecorder`.
- `Tab + Mic` mixes captured tab audio and microphone through `AudioContext` / `MediaStreamDestination`.
- Tab captures are saved to Saved Takes and also to the WMS Local Library, subject to the existing per-file size limit.
- Capture stops automatically if the selected shared surface ends.
- If the selected surface contains no audio track, UI instructs the user to choose the current tab and enable tab-audio sharing.
- This is fully local; it does not use Cloud Run or yt-dlp.
